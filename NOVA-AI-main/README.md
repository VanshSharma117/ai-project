# 🤖 Full-Stack AI Chatbot

A modern AI chatbot built using **React.js**, **Express.js**, **Node.js**, and the **Groq API**. This project provides a clean, responsive, and user-friendly chat interface that allows users to interact with an AI assistant in real time. The chatbot is designed with a full-stack architecture, where the React frontend communicates with an Express backend, which securely handles API requests to the Groq AI model.

---

## 📖 Description

This Full-Stack AI Chatbot demonstrates how to build an AI-powered conversational web application using modern JavaScript technologies. The frontend is developed with React, providing a fast and interactive user experience, while the backend is powered by Express.js and Node.js to securely manage API communication.

The chatbot allows users to send prompts and receive intelligent AI-generated responses almost instantly. The backend protects sensitive API keys by handling all communication with the Groq API server, ensuring better security compared to directly exposing API credentials in the frontend.

This project is suitable for beginners learning full-stack development as well as developers looking to understand AI API integration in modern web applications.
